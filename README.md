# ПрофиДоска — Доска объявлений и услуг (Прототип для DLE 19/20)

Интерактивный прототип доски объявлений и услуг в лаконичной, строгой стилистике сервиса **Profi.ru** (минимализм, бенто-сетка, опора на свободное пространство и отступы, отсутствие визуального шума).

Проект спроектирован для 100% бесшовной посадки на CMS **DataLife Engine (DLE 19/20)** с поддержкой модуля `dle-billing`, нативных доп. полей `xfields` и раздельной регистрации пользователей.

---

## Что реализовано в прототипе

1. **Главная страница и каталог (в стиле Profi.ru)**:
   - Шапка с переключателем гео-локации (Барнаул и города края).
   - Поисковая строка с быстрыми тегами («Ремонт квартир», «Автоэлектрик», «Сантехник»).
   - **Бенто-сетка категорий** с иконками, счетчиками и выделением платных категорий.
   - Фильтры ленты: *Все предложения*, *⭐ VIP объявления*, *🎬 С видеообзором*, *🏢 Рекламодатели*.
   - Интерактивная кнопка **«Показать телефон»** с мгновенным снятием маски номера.

2. **Форма подачи объявления (`addnews.tpl`)**:
   - Выбор категорий DLE (с индикатором стоимости размещения).
   - Загрузка нескольких фото (имитация нативного загрузчика изображений DLE с генерацией превью).
   - Поле для видеообзора (YouTube / RuTube).
   - **Блок платных услуг `dle-billing`**: VIP-статус, закрепление в топе, поднятие в поиске с автоматическим расчетом стоимости.
   - Мгновенная публикация с добавлением карточки в ленту и списанием с баланса.

3. **Раздельная регистрация (`registration.tpl`)**:
   - Переключатель ролей: **«Клиент» (Группа ID 4)** vs **«Рекламодатель» (Группа ID 6)**.
   - Динамическое отображение полей организации/мастера.
   - Готовая логика для упаковки в XML-плагин DLE.

4. **Детальная страница объявления (`fullstory.tpl`)**:
   - Галерея фотографий с превью.
   - Блок встроенного видео.
   - Блок автора с бейджем «Рекламодатель», рейтингом и кнопкой быстрой связи.

5. **Личный кабинет и баланс (`dle-billing`)**:
   - Текущий баланс пользователя.
   - Пополнение счета через СБП/карты.
   - Список «Мои объявления» с рабочей кнопкой **«Поднять на 1 место» (99 ₽)**.

## Соответствие файлам DLE 19/20

| Экран прототипа | Шаблон DLE | Назначение |
| :--- | :--- | :--- |
| Шапка, поиск, сетка | `templates/board/main.tpl` | Базовый каркас темы DLE |
| Карточка в ленте | `templates/board/shortstory.tpl` | Вывод объявления с тегами `[xfvalue_...]` |
| Просмотр объявления | `templates/board/fullstory.tpl` | Полное объявление, плеер видео, галерея фото |
| Форма подачи | `templates/board/addnews.tpl` | Подача объявления с загрузкой файлов |
| Регистрация | `templates/board/registration.tpl` | Выбор роли «Клиент» / «Рекламодатель» |
| Кабинет и баланс | `templates/board/userinfo.tpl` | Профиль, баланс `dle-billing` и свои публикации |

## Запуск прототипа

Просто откройте файл `index.html` в любом современном браузере:
- Двойной клик по `index.html` в проводнике Windows
- Либо через любой локальный веб-сервер (Live Server, `npx serve`, `python -m http.server`)
